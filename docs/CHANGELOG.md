# 版本记录

只记用户能感知的变化。1.3 到 1.8 是界面反复调整的阶段，那几版布局已经不存在了，不再列。

## 3.0

- 关于页加「检查更新」，点一下拉 GitHub 最新 release，比当前版本新就打开浏览器
- 映射页固定 16 个键：ZL ZR L R - + Y X B A LS RS 上 下 左 右，目标键用同一张表
- 振动页加「试振」按钮；减号挪到星星左边
- 手柄按键不再操作界面：方向键和确认键被统一拦掉，只有按键测试页还认
- 应用时状态行只显示「正在写入 3/12」，不再打十六进制帧

## 2.9.3

- 取消配对时同时清掉 `GameMacro` 和 `Pocket Controller` 两个系统配对身份，1.2 秒后复查一次
- 四个页面锁定竖屏
- 按键测试的摇杆行程改为 `rO - rI`，推到底时帽沿贴住外圈

## 2.9.2

- 摇杆页加曲线卡片：左右切换、默认/快速/缓慢三档、两个可拖控制点
- 映射的目标键可以直接点开选择器，B 能映射成 `-`
- 振动改成四档，点 `−` / `+` 或星标会发一次试振
- 体感页标题改成「体感映射」

## 2.9.1

- 修启动闪退：底部导航布局的根节点写成了抽象类 `NavigationBarView`，`LayoutInflater` 实例化不了
- 加 Robolectric 冒烟测试，在 JVM 上真实跑四个 Activity 的 `onCreate`

## 2.9

- 引入 Material Components 1.9.0 和 AppCompat 1.6.1，整个界面重画
- 底部导航、卡片、按钮、开关、滑块、Tab、Chip、Snackbar 换成 Material 组件
- 电池、范围条、校准环、按键测试手柄图仍然自绘

## 2.5

- 底部三个页签：设备 / 宏配置 / 关于
- 按键测试前先把手柄切到 BETA 模式，否则收不到私有帧
- 陀螺仪和摇杆校准改成点一下开始，等手柄上报结果
- 设备列表只显示名称和信号强度
